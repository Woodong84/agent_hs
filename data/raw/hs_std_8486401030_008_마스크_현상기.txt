【품목명】 마스크 현상기
【영문명】 Mask Developer System ; SFG3000
【HS Code】 8486.40-1030 (HSK2022: 8486401030)
【제조공정】 제2장 마스크 제작

【물품설명】
용 도
  ◈   Mask 제조공정 중 노광 공정이 끝난 후 Mask의 PR(Photoresist) 중 필요 없는 부분을 제거하여 
Pattern을 형성시키는 현상 설비
   주요 구성 및 기능
  ◈   SMIF Loader/Unloader부 : Mask가 Loading 하는 부분으로 2매 이상 동시에 진행이 가능할 수 
있도록 Port가 2개 장착되어 있음
  ◈   Transfer Robot 및 Aligner부 : Mask 이송 및 Mask를 정렬하는 장치
  ◈   PEB(Post Exposure Bake) Module : Expose(노광) 후 Electron beam을 맞은 PR 부분에 Pattern 
형성이 잘 이루어질 수 있도록 Bake 하는 Module
  ◈   Developer Module : Bake가 끝난 후 Mask PR의 필요 없는 부분은 제거하여 Pattern을 
형성하기 위해 현상액을 Fan과 NS Nozzle을 통해 Mask 표면에 분사하는 원리
   동작원리
  ◈   Mask가 SMIF Indexer부에서 Transfer Robot에 의해 PEB Module에 이송됨 → PEB Module는 
Mask에 현상이 잘 이루어지도록 Heater를 이용 Mask에 열을 가함 → PEB 공정을 마친 Mask는 
다시 Developer Module로 Robot에 의해 이송됨 → Developer Module에서 현상액을 Fan과

NS Nozzle을 통하여 Mask 표면에 분사화학원리를 이용하여 Mask를 현상함 → 현상이 완료된 
Mask는 다시 Unloading됨

【결정사유】
본 물품은 Mask 제조공정 중 노광 공정이 끝난 후 Mask의 PR 중 필요 없는 부분을 
제거시켜 Pattern을 형성시키는 현상 설비임
   관세율표 제8486호에는 전자집적회로의 제조에 전용 또는 주로 사용되는 기계가 
분류되고, 제8486.40호에는 마스크와 레티클의 제조용·수리용 기계와 기기가 분류되며, 
포토레지스트를 도포·현상하는 기계를 제8486.40-1030호에 분류토록 규정하고 있음
   따라서 본 물품은 포토마스크 제조공정 중 Mask의 PR의 필요 없는 부분을 제거하여 
Pattern을 형성시키는 물품으로, 현상을 수행하는 기계이므로 제8486.40-1030호에 
분류함
