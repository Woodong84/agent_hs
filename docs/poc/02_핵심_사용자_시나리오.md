* 상황 : [언제, 어떤 상황에서 사용하는가]\
  반도체 제조사 수출 담당자가 신규 도입된 웨이퍼 이송용 FOUP(Front Opening Unified Pod)을 미국 고객사로 수출하게 되었다.\

  관세사에 문의하면 회신까지 1~2일이 소요되어 선적 일정이 촉박한 상황에서 Agent를 통해 빠른 1차 판단을 얻고자 한다.

  유사 코드 간 차이점을 파악하여 담당자가 5분 내 최종 확정 판단을 내릴 수 있도록 지원 필요

* 사전 조건 : [시나리오 시작 전 필요한 상태]\
  - VectorDB에 관세청 품목분류 사례집(반도체 관련 섹션) 및 HS 해설서 적재 완료\

**시나리오 2 :****&#x20;**&#xC720;사 코드 상충 - 담당자 재분류 판단 지원

Q2 답변 수신 → 단일 코드로 좁혀지면 권장 코드 출력 후 종료.\
여전히 불확실하면 강제 종료 조건 진입

최대 2턴 규칙 적용. Q3는 보조 참고용으로만 사용

**종료**

2턴 후에도 단일 코드 미수렴 → Clarification 강제 종료\
→ "추가 정보로도 분류가 어렵습니다. 관세청 품목분류 사전심사 또는 관세사 확인을 권장합니다." 메시지 출력

4. 근거 추적 포맷(출처 메타데이터) 정의\
   - 근거 1개의 필수 메타데이터 필드 정의

|        |          |                                                                                                 |
| ------ | -------- | ----------------------------------------------------------------------------------------------- |
| **구분** | **항목**   | **증적**                                                                                          |
| 필수     | 문서명      | 공식 문서 전체 명칭 예: "관세청 품목분류 사례집 2023년판"                                                            |
| 필수     | 발행연도·버전  | 문서 발행 연도 또는 버전 정보. RAG 문서 최신성 추적에 필수 예: "2023년판" / "WCO HS 2022 Edition"                        |
| 필수     | 페이지·섹션   | 해당 내용이 수록된 페이지 번호 또는 섹션 번호 예: "p.247" / "§38.24-3" / "제3절 2항"                                   |
| 필수     | 인용 문장    | 분류 기준 결정에 직접 사용된 핵심 문장 1~2문장. 요약 아닌 원문 발췌 예: "플라스틱제 운반용 케이스로서 특정 물품 운반 전용으로 제작된 것은 3923호에 분류한다" |
| 필수     | 유사도 점수   | VectorDB 코사인 유사도 점수 (0~1). 근거 신뢰도 표시 및 임계값 비교에 사용 예: 0.87                                       |
| 선택     | 청크 ID    | VectorDB 내부 청크 식별자. 동일 근거 재현·디버깅 목적 예: "chunk_3923_p247_001"                                    |
| 선택     | 관련 HS 코드 | 해당 인용 문장이 지지하는 HS 코드 (근거-코드 연결 추적용) 예: "3923.10"                                                |

* 핵심효과 : 감사 로그 자동 완성\
  - evidence 메타데이터가 구조화되면 "왜 이 코드를 추천했는가"를 문서명·페이지·인용 문장 수준까지 자동으로 추적 가능함.\
  담당자가 별도 소명 자료를 작성하지 않아도 로그 출력만으로 관세 감사 대응이 가능한 구조가 완성됨.
